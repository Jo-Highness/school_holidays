# Screenshots — to be supplied

The main [`README.md`](../README.md) references the images listed below. They are **not yet
in the repository** and must be provided by the maintainer. Until then the README shows them
as placeholders.

Please capture them from a running Home Assistant instance with the integration configured,
and drop the files into this `images/` folder using the exact file names below.

| File name | What it should show | Recommended size | Theme |
| --- | --- | --- | --- |
| `config-flow.png` | The Add-Integration config flow: the **Country** dropdown (step 1) and/or the **State / region** dropdown (step 2). | ~800 px wide (dialog width) | Light |
| `entities.png` | The **device page** for one configured region, showing the three entities: *School holidays today*, *School holidays tomorrow*, *Next school holiday*. | ~1000 px wide | Light |
| `dashboard.png` | An example Lovelace card using the entities — e.g. an Entities card with today / tomorrow / next holiday. | ~600–800 px wide | Light |

## Guidelines

- **Format:** PNG, with the exact file names above (the README links are case-sensitive).
- **Theme:** Light theme is the baseline. Optional dark-theme variants may be added later as
  `*-dark.png`; if so, wire them into the README as well.
- **Crop:** Trim to the relevant dialog/card. Avoid capturing unrelated sidebar content.
- **Privacy:** Check that no personal data (real names, tokens, addresses) is visible before
  committing.

> **Maintainer action required:** these screenshots need to be produced and added by the
> maintainer; do not fabricate or generate placeholder images.
